контентная часть интерфейса, состоящий из двух основных разделов, расположенных вертикально.

РАЗДЕЛ 1 — Полученные сертификаты

Отобразите горизонтальную сетку карточек сертификатов (4 карточки в строке на десктопе).

Каждая карточка сертификата содержит:

Прямоугольный контейнер карточки со скруглёнными углами и заметной декоративной рамкой.
Внутри карточки элементы выровнены по центру по вертикали:
Крупный круглый значок (бейдж) в верхней части карточки.
Небольшая подпись с годом внутри или рядом с бейджем.
Блок с названием сертификата под бейджем.
Небольшой индикатор статуса под названием (в виде бейджа или плашки).
Всё содержимое карточки центрировано.
Между карточками одинаковые отступы.
Размер карточек средний, с визуальным акцентом.
РАЗДЕЛ 2 — Доступные сертификаты

Под первым разделом разместите вертикальный список доступных сертификатов.

Каждый элемент списка — широкая горизонтальная карточка со скруглёнными углами и мягкой тенью.

Структура каждой строки:

ЛЕВАЯ ЧАСТЬ

Квадратный контейнер с крупной иконкой по центру.
ЦЕНТРАЛЬНАЯ ЧАСТЬ

Вертикальный блок с содержимым:
Заголовок.
Короткое описание.
Небольшой вертикальный список этапов (3 пункта).
ПРАВАЯ ЧАСТЬ

Блок прогресса, выровненный по правому краю:
Горизонтальная полоса прогресса.
Небольшой текстовый индикатор прогресса.
Основная кнопка действия под полосой прогресса.
ПРАВИЛА МАКЕТА

Строки располагаются вертикально с одинаковыми отступами между ними.
Левая зона с иконкой имеет фиксированную ширину.
Центральная зона с текстом растягивается и занимает всё доступное пространство.
Правая зона с прогрессом имеет фиксированную ширину и выравнивается по правому краю.
Всё содержимое строки выровнено по центру по вертикали.
ОБЩИЙ СТИЛЬ

Светлый фон страницы.
Карточки имеют мягкие тени и скруглённые углы.
Чёткие отступы между разделами и элементами.
Используется современный стиль интерфейса дашборда.
Макет должен быть адаптивным и корректно перестраиваться на меньших экранах. :::
