model SecretPage {
  id        String   @id @default(cuid())
  slug      String   @unique
  title     String
  filePath  String   // например "secret-pages/pa-characters/index.html"
  isActive  Boolean  @default(true)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([slug])
  @@index([isActive])
}

model UserAccess {
  id           String   @id @default(cuid())
  userId       String
  resourceType String   // "page", "challenge", "course", "feature"
  resourceId   String   // ID страницы, испытания, курса
  grantedBy    String   // "key_<keyId>" или "admin_<adminId>"
  grantedAt    DateTime @default(now())
  expiresAt    DateTime? // опционально
  createdAt    DateTime @default(now())

  @@unique([userId, resourceType, resourceId])
  @@index([userId])
  @@index([resourceType, resourceId])
  @@index([grantedBy])
}

model Key {
  id          String   @id @default(cuid())
  code        String   @unique
  actionsJson Json     // логика что даёт ключ
  maxUses     Int      @default(1)
  usedCount   Int      @default(0)
  expiresAt   DateTime?
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@index([code])
  @@index([isActive])
}
model KeyUse {
  id        String   @id @default(cuid())
  keyId     String
  userId    String
  usedAt    DateTime @default(now())
  key       Key      @relation(fields: [keyId], references: [id], onDelete: Cascade)
  user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([keyId, userId]) // один пользователь — один раз использовал ключ
  @@index([keyId])
  @@index([userId])
}


2. Админка секретных страниц
Расположение: /admin/secret-pages/ - добавить пункт меню после пункта "Курсы". Доступ админам и менеджерам. isAdmin isManager

Функции:

Список всех страниц (таблица: slug, title, description, isActive, кнопки)
Создание страницы
Редактирование
Удаление

3. Создание страницы
Форма:

Поле slug (латиница, только буквы/цифры/дефис)

Поле title

Поле description (опционально)

Поле courseSlug (выбор из существующих курсов в БД)

Поле для загрузки HTML файла (один файл)

Поле для загрузки изображений (множественный выбор)

Логика сохранения:

Проверить уникальность slug

Создать папку: public/secret-pages/[slug]/

Сохранить загруженный HTML как index.html в этой папке

Сохранить все изображения в папку public/secret-pages/[slug]/images/ с оригинальными именами

В HTML заменить все абсолютные ссылки на изображения на относительные (/secret-pages/[slug]/images/...)

Найти все src="http..."
Скачать каждое изображение в папку /secret-pages/[slug]/images/...
Заменить src на локальный путь

Записать в БД: slug, title, description, courseSlug, filePath = secret-pages/[slug]/index.html, isActive = true


4. Редактирование страницы
Форма:

Те же поля, что при создании

Slug нельзя менять (или можно с проверкой уникальности и переименованием папки на диске)

Можно загрузить новый HTML файл (заменяет старый)

Можно загрузить новые изображения (добавляются в папку images)

Список уже загруженных изображений с возможностью удаления

Логика:

При загрузке нового HTML — перезаписать index.html

При добавлении изображений — сохранить в папку images

При удалении изображения — удалить файл с диска

5. Удаление страницы
Логика:

Удалить запись из БД

Удалить папку public/secret-pages/[slug]/ рекурсивно (все файлы)
