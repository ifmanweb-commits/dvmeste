# Техническое задание: Система обучающих подсказок (Onboarding Tips)

## 1. Общее описание

Система позволяет администраторам и модераторам создавать обучающие подсказки для пользователей. Подсказки привязываются к конкретным страницам (по полному URL с query-параметрами). После закрытия подсказка больше никогда не показывается этому пользователю.

---

## 2. Типы подсказок

### 2.1 Тост (Toast)
- Всплывающее уведомление в правом нижнем углу экрана
- Анимация: вылетает из-за правого края, при закрытии — улетает вправо
- Не закрывается автоматически — только по кнопке "✕"
- Показываются по одному, последовательно
- Между закрытием одного тоста и появлением следующего — пауза 1 секунда
- Текст с переносом строк (white-space: pre-wrap)

### 2.2 Модальное окно (Modal)
- Центрированное окно поверх контента
- На десктопе: обычное модальное окно (нейтральный дизайн, не ассоциируется с ошибкой)
- На мобильных устройствах: на весь экран, белый фон
- Не имеет задержки — показывается сразу (при загрузке страницы)
- Не закрывается автоматически — только по кнопке закрытия
- Текст с переносом строк (white-space: pre-wrap)

---

## 3. Правила показа

### 3.1 Для страницы
- Подсказка привязана к **полному URL** (включая query-параметры)
- Примеры разных страниц: `/account/articles` и `/account/articles?page=2` — это разные страницы
- Маски URL не поддерживаются

### 3.2 Для пользователя
- Подсказка показывается **один раз в жизни пользователя**
- После закрытия — больше никогда не показывается
- Закрытие запоминается персонально для каждого пользователя

### 3.3 Порядок показа
- Если на странице есть **модальное окно** — оно показывается первым
- После закрытия модального окна — показываются **тосты** (если есть)
- Тосты показываются **по одному**, в порядке возрастания `delay_seconds`
- Между тостами — пауза 1 секунда после закрытия предыдущего

### 3.4 Задержка
- У тостов можно указать задержку в секундах (от 0 и выше)
- Задержка отсчитывается с момента загрузки страницы
- Если задержка = 0 — тост появляется сразу (после модального окна, если оно есть)
- У модальных окон задержки нет

## 4. Модели данных (Prisma)

```prisma
model OnboardingTip {
  id            String        @id @default(cuid())
  title         String        // заголовок подсказки
  message       String        @db.Text  // текст подсказки (с поддержкой переносов)
  type          TipType       // TOAST или MODAL
  pageUrl       String        // полный URL страницы (с query-параметрами)
  delaySeconds  Int           @default(0)  // только для TOAST
  isActive      Boolean       @default(true)
  createdAt     DateTime      @default(now())
  updatedAt     DateTime      @updatedAt
  
  dismissals    UserTipDismissal[]
}

enum TipType {
  TOAST
  MODAL
}

model UserTipDismissal {
  id            String        @id @default(cuid())
  userId        String
  tipId         String
  dismissedAt   DateTime      @default(now())
  
  user          User          @relation(fields: [userId], references: [id], onDelete: Cascade)
  tip           OnboardingTip @relation(fields: [tipId], references: [id], onDelete: Cascade)
  
  @@unique([userId, tipId])
}
```

## 5. Админ-панель

**Раздел:** `/admin/onboarding`

**Доступ:** Администраторы и модераторы (isAdmin = true ИЛИ isManager = true)

### 5.1 Структура

Две вкладки:
- **Тосты** — только подсказки с `type = TOAST`
- **Окна** — только подсказки с `type = MODAL`

### 5.2 Список подсказок

Таблица с колонками:
| Заголовок | URL | Задержка (сек) | Статус | Действия |
|-----------|-----|----------------|--------|----------|
| Как написать статью | /account/articles | 2 | Активна | ✏️ 🗑️ 👁️ |

Фильтр сверху: поле ввода URL (текстовый поиск по `pageUrl`)

### 5.3 Форма создания/редактирования

**Поля:**

| Поле | Тип | Обязательное | Примечание |
|------|-----|--------------|------------|
| Заголовок | Текст | Да | |
| Текст | Текстовая область (textarea) | Да | Поддержка переноса строк |
| URL страницы | Текст | Да | Полный URL (например, `/account/articles?page=2`) |
| Задержка (сек) | Число | Только для тостов | По умолчанию 0 |
| Активна | Чекбокс | Нет | По умолчанию true |

**Кнопки:**
- Сохранить
- Отмена
- Предпросмотр (см. п. 5.4)

### 5.4 Предпросмотр

- Кнопка "Предпросмотр" открывает модальное окно с точной копией того, как подсказка будет выглядеть у пользователя
- Для тоста — в правом нижнем углу превью (внутри модалки)
- Для модального окна — в центре превью

## 6. Клиентская часть

### 6.1 API эндпоинт

**GET** `/api/onboarding?url=<current_url>`

**Ответ:**
```json
{
  "modal": {
    "id": "123",
    "title": "Добро пожаловать",
    "message": "Текст с переносами\nвторая строка"
  } | null,
  "toasts": [
    {
      "id": "456",
      "title": "Как написать статью",
      "message": "Перейдите в раздел...",
      "delaySeconds": 2
    }
  ]
}
```

**Логика:**
- Ищем все активные подсказки с `pageUrl = current_url`
- Фильтруем: исключаем те, у которых есть `UserTipDismissal` для текущего пользователя
- Отделяем модальное окно (берём первое, если их несколько)
- Тосты сортируем по `delaySeconds` (asc), затем по `createdAt`

### 6.2 Компонент-провайдер

- Встраивается в корневой layout (или в layout личного кабинета)
- При загрузке страницы вызывает API с текущим URL
- Отображает модальное окно (если есть)
- После закрытия модалки — запускает очередь тостов
- Для каждого тоста: ожидает `delaySeconds`, показывает, ждёт закрытия, затем пауза 1 секунда, затем следующий тост
- При закрытии любой подсказки — отправляет запрос на сервер для сохранения `UserTipDismissal`

### 6.3 Внешний вид

**Тост:**
- Фиксированная позиция: bottom: 20px, right: 20px
- Ширина: 320px (на мобильных — 90% ширины экрана)
- Белый фон, тень, скруглённые углы
- Заголовок — жирный шрифт
- Текст — обычный, с переносом строк
- Кнопка закрытия — крестик в правом верхнем углу

**Модальное окно (десктоп):**
- Ширина: 500px, центрировано
- Белый фон, тень, скруглённые углы
- Кнопка закрытия — крестик или "Понятно"

**Модальное окно (мобильный):**
- На весь экран (width: 100%, height: 100%)
- Белый фон
- Кнопка закрытия внизу или вверху

### 6.4 Анимации

- **Тост при появлении:** анимация вылета из-за правого края (translateX → 0)
- **Тост при закрытии:** анимация улетания вправо (translateX)
- **Модальное окно:** fade-in (опционально)

## 7. Server Actions

### 7.1 Для админки
- `createTip(data)` — создание подсказки
- `updateTip(id, data)` — обновление
- `deleteTip(id)` — удаление (каскадно удаляет все dismissals)
- `getTips(filters)` — получение списка с фильтрацией
- `getTipById(id)` — получение одной подсказки

### 7.2 Для клиента
- `dismissTip(tipId)` — сохраняет закрытие подсказки пользователем (вызывается из API, но можно и напрямую)
