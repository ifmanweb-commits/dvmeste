1️⃣ Общая информация
Проект: Давай вместе — каталог психологов
Технологии: Next.js 16 (App Router), Prisma, TypeScript, node-cron
Тип задачи: Реализация случайного порядка отображения психологов в каталоге с ежедневным обновлением через cron

2️⃣ Модель данных
Добавить в schema.prisma в модель User:

prisma

  // ... существующие поля
  sortOrder Int @default(0)
}
Создать миграцию:

bash
npx prisma migrate dev --name add_sort_order
npx prisma generate
3️⃣ Server Action для перегенерации сортировки
Файл: lib/actions/shuffle-catalog.ts

typescript
"use server";

import { prisma } from "@/lib/prisma";

export async function shuffleCatalog() {
  // Получаем всех активных психологов
  const psychologists = await prisma.user.findMany({
    where: { isPublished: true, status: "ACTIVE" },
    select: { id: true }
  });
  
  if (psychologists.length === 0) return;
  
  // Перемешиваем массив ID
  const shuffledIds = psychologists
    .map(p => p.id)
    .sort(() => Math.random() - 0.5);
  
  // Массовое обновление sortOrder
  for (let i = 0; i < shuffledIds.length; i++) {
    await prisma.user.update({
      where: { id: shuffledIds[i] },
      data: { sortOrder: i + 1 }
    });
  }
}
4️⃣ API роут для ручного запуска (опционально)
Файл: app/api/admin/shuffle-catalog/route.ts

typescript
import { NextResponse } from "next/server";
import { requireAdmin } from "@/lib/auth/require";
import { shuffleCatalog } from "@/lib/actions/shuffle-catalog";

export async function POST() {
  await requireAdmin();
  await shuffleCatalog();
  return NextResponse.json({ success: true });
}
5️⃣ Cron-задача
Файл: lib/cron-jobs.ts

typescript
import cron from "node-cron";
import { shuffleCatalog } from "@/lib/actions/shuffle-catalog";

export function startCronJobs() {
  cron.schedule("0 3 * * *", async () => {
    console.log("[Cron] Запуск обновления порядка каталога...");
    try {
      await shuffleCatalog();
      console.log("[Cron] ✅ Порядок каталога обновлён");
    } catch (error) {
      console.error("[Cron] ❌ Ошибка:", error);
    }
  });
  
  console.log("[Cron] Задачи зарегистрированы");
}

7️⃣ Обновление каталога
В lib/actions/client-catalog.ts изменить сортировку по умолчанию:

typescript
// Было:
orderBy: { createdAt: "desc" }

// Стало:
orderBy: { sortOrder: "asc" }
При других типах сортировки (цена, уровень, возраст) — использовать соответствующий orderBy, без изменений.
