## 📋 ТЗ: Улучшение мобильной навигации в профиле психолога

### 1️⃣ Проблема

Сейчас страница `/account/profile` использует JavaScript-вкладки (tabs). Это создаёт проблемы на мобильных устройствах:

- При перезагрузке страницы всегда открывается первая вкладка
- Нельзя отправить прямую ссылку на вкладку "Фотографии"
- Навигация между вкладками не сохраняется в истории браузера
- Мобильный интерфейс не оптимизирован (горизонтальные вкладки плохо скроллятся)

---

### 2️⃣ Решение

**Использовать URL-параметр `tab` для управления активной вкладкой**

URL страницы будет выглядеть так:
- `/account/profile?tab=basic` — личные данные
- `/account/profile?tab=detailed` — подробная информация
- `/account/profile?tab=photos` — фотографии
- `/account/profile?tab=documents` — документы

**Преимущества:**
- При перезагрузке страницы открывается та же вкладка
- Можно отправить ссылку на конкретный раздел
- Кнопка "назад" в браузере работает
- Для мобильных можно сделать удобный bottom navigation

---

### 3️⃣ Техническая реализация

#### 3.1. Изменить страницу `/account/profile/page.tsx`

**Было:**
```tsx
export default async function ProfilePage() {
  // ... получение данных
  return <ProfileFormContainer user={user} availableParadigms={availableParadigms} />;
}
```

**Стало:**
```tsx
import { redirect } from "next/navigation";

type PageProps = {
  searchParams: Promise<{ tab?: string }>;
};

export default async function ProfilePage({ searchParams }: PageProps) {
  const params = await searchParams;
  const activeTab = params.tab || "basic"; // basic, detailed, photos, documents
  
  // ... получение данных
  
  return (
    <ProfileFormContainer 
      user={user} 
      availableParadigms={availableParadigms}
      activeTab={activeTab}
    />
  );
}
```

#### 3.2. Изменить `ProfileFormContainer.tsx` (клиентский компонент)

**Что нужно сделать:**

1. **Читать `activeTab` из пропсов**
2. **При переключении вкладки — обновлять URL через `router.push`**
3. **Убрать локальное состояние `activeTab`** (теперь управляется через URL)

**Ключевые изменения:**

```tsx
"use client";

import { useRouter } from "next/navigation";
import { useCallback } from "react";

interface ProfileFormContainerProps {
  user: UserWithDocuments;
  availableParadigms: string[];
  activeTab: string; // ← новый пропс
}

export function ProfileFormContainer({ 
  user, 
  availableParadigms, 
  activeTab 
}: ProfileFormContainerProps) {
  const router = useRouter();
  
  // Переключение вкладки с обновлением URL
  const setActiveTab = useCallback((tab: string) => {
    const url = new URL(window.location.href);
    url.searchParams.set("tab", tab);
    router.push(url.toString(), { scroll: false });
  }, [router]);
  
  // ... остальная логика (состояния user, handlers и т.д.)
  
  return (
    <div>
      {/* Навигация — теперь активная вкладка из пропса */}
      <div className="flex border-b">
        <button
          onClick={() => setActiveTab("basic")}
          className={activeTab === "basic" ? "border-blue-600" : ""}
        >
          Личные данные
        </button>
        {/* ... остальные кнопки */}
      </div>
      
      {/* Контент — показываем только активную вкладку */}
      {activeTab === "basic" && <BasicTab user={user} onChange={handleBasicChange} />}
      {activeTab === "detailed" && <DetailedTab user={user} onChange={handleDetailedChange} />}
      {activeTab === "photos" && <PhotosTab user={user} onUpload={handlePhotoUpload} />}
      {activeTab === "documents" && <DocumentsTab user={user} />}
    </div>
  );
}
```

#### 3.3. Мобильная навигация

Для мобильных устройств добавить **bottom navigation** (или выпадающий список) вместо горизонтальных вкладок:

```tsx
// Для мобильных (sm:hidden)
<div className="fixed bottom-0 left-0 right-0 bg-white border-t flex justify-around p-2 sm:hidden">
  <button onClick={() => setActiveTab("basic")}>👤</button>
  <button onClick={() => setActiveTab("detailed")}>📝</button>
  <button onClick={() => setActiveTab("photos")}>📸</button>
  <button onClick={() => setActiveTab("documents")}>📄</button>
</div>

// Для десктопа (оставить горизонтальные вкладки)
<div className="hidden sm:flex border-b">
  {/* ... */}
</div>
```

### 4️⃣ Что не нужно менять

- **Server Actions** (`updateBasicProfile`, `updateDetailedProfileDraft` и т.д.) — остаются без изменений
- **Логика работы с черновиком** — не меняется
- **Компоненты вкладок** (`BasicTab`, `DetailedTab`, `PhotosTab`, `DocumentsTab`) — можно вынести в отдельные компоненты для чистоты кода
