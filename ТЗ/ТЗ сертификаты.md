## ТЗ: Админка генератора сертификатов

### Расположение
`/admin/certificate-templates/`

---

### Модель БД

```prisma
model CertificateTemplate {
  id          String   @id @default(cuid())
  name        String   // "Сертификат ПП-1"
  slug        String   @unique
  backgroundUrl String  // путь к фоновой картинке
  fieldsJson  Json     // координаты и настройки полей
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

model Certificate {
  id          String   @id @default(cuid())
  templateId  String
  userId      String   // кому выдан
  dataJson    Json     // заполненные значения полей
  imageUrl    String   // путь к сгенерированному PNG
  issuedAt    DateTime @default(now())
  template    CertificateTemplate @relation(fields: [templateId], references: [id])
  user        User     @relation(fields: [userId], references: [id])
}
```

### Интерфейс админки

**Список шаблонов (`/admin/certificate-templates`)**
- Таблица: название, slug, активен
- Кнопка "Создать шаблон"

**Создание/редактирование (`/admin/certificate-templates/new`)**

Форма:
- Поле "Название"
- Поле "Slug"
- Загрузка фоновой картинки (PNG/JPEG, рекомендуется 1200x800)
- Чекбокс "Активен"

**Редактор полей:**
- Список полей с возможностью добавлять/удалять
- Для каждого поля:
  - Имя поля (fullName, courseName, issuedAt...)
  - Метка (для админки)
  - X, Y координаты (можно кликнуть на превью картинки)
  - Размер шрифта
  - Цвет (color picker)
  - Шрифт (выпадающий список)
  - Выравнивание (лево/центр/право)

**Превью:**
- Отображается фоновая картинка
- Поверх неё нарисованы прямоугольники с именами полей
- Можно кликнуть мышкой — координаты подставляются в выбранное поле

**Тестирование:**
- Внизу страницы блок "Тестовая генерация"
- Поля для ввода тестовых значений (подставляются из списка полей)
- Кнопка "Сгенерировать тестовый сертификат"
- Показывается полученное PNG-изображение

---

### API для генерации

**`/api/admin/certificate-templates/[id]/preview`** (POST)
- Тело: значения полей (JSON)
- Возвращает: PNG-изображение (использовать `sharp`)

**`/api/admin/certificate-templates/[id]/generate`** (POST)
- Тело: значения полей, userId
- Генерирует PNG, сохраняет в `/public/certificates/[id].png`
- Создаёт запись в Certificate
- Возвращает URL к картинке

---

### Библиотеки
- `sharp` — для наложения текста на картинку
- `@react-pdf/renderer` — альтернатива (PDF, сложнее с кириллицей)

---

### Логика работы

1. Админ загружает фон и расставляет поля
2. В ЛК психолога при получении сертификата — кнопка "Скачать сертификат"
3. Запрос на API с данными пользователя (имя, курс, дата)
4. Генерация PNG на лету (или из кэша)
5. Отдача файла
