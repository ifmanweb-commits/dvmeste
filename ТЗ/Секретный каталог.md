== Секретный каталог
В форме выдачи доступа, сделать новый тип кроме Секретной страницы - "Секретный каталог".
При его выборе - показывать вместо селекта для айди - новый селект "Может: Читать / Разместиться"
При выдаче доступа - в базе писать тип - catalog, вместо айди - secret-catalog
А в поле metaData сохранить может человек read или included
Всё остальное - так же.
При приёме и обработке параметров доступа - проверять что ресурсайди может прийти из формы пустым если ресурс тайп - каталог.

== Сам каталог
Находится по адресу /account/secret-catalog/
При входе - проверяет доступ пользователя.
Если доступ есть - показывает секретный каталог.

Чтобы показать секретный каталог, нужно опираться на страницу из файла
private\secret-pages\ppsy-test\index.html
Сверху - два описания как на этой странице. А ниже - вывод карточек психологов.
Но Верстка раздела в стиле других разделов, вроде
http://localhost:3000/account/certification
чтобы было ощущение что это единая система Заголовки, шрифты, цвета и т.д.

Читаем из таблицы UserAccess пользователей, у которых тип доступа - catalog, а в metaData содержится информация что они included.
Находим данные этих пользователей из User
Фильтруем чтобы в metaData.secretCatalog.optIn был true
Выводим карточки этих психологов в случайном порядке.
Карточка психолога содержит:
- Фото-аватар
- Имя
- shortBio
- количество бесплатных консультаций (metaData.secretCatalog.freeSessions)
- цена за консультации последующие (metaData.secretCatalog.price)
- контакт из User.contactInfo
Если у пользователя нет аватара - выводить круглую заглушку с инициалами поверх.

== Размещение психолога в секретном каталоге
http://localhost:3000/account/secret-catalog
Если пользователь с пермишн инклюдед 
	В плашке "для выпускников" показываем формочку
	"Показывать мои данные в этом каталоге" - чекбокс большой красивый
	"Бесплатных сессий для учеников я даю" - цифровой инпут
	"Цена для учеников" - цифровой инпут
	Кнопка "Сохранить"
Если пользователь ставит чекбокс включенным - сохранить эти данные в User.metaData
по образу:
metaData: {
  "secretCatalog": {
    "optIn": true,
    "freeSessions": 1,
    "price": 3000,
  }
}
Другие поля мета-дата не переписывать. Только secretCatalog.
Если пользователь убрал чекбокс размещения - будет так:
metaData: {
  "secretCatalog": {
    "optIn": false,
  }
}
