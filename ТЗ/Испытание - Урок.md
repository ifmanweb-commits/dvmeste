# Техническое задание: Новый тип испытания — Урок (Lesson)

## 1. Общее описание

Добавляется новый тип испытания `LESSON`. Урок — это HTML-страница с обучающим контентом (текст, видео, ссылки). Пользователь считается прошедшим урок, если он хотя бы раз открыл страницу урока. Прохождение урока отслеживается автоматически, без кнопки "Завершить".

Уроки используются в сертификациях вместе с тестами и работами. Сертификация может требовать выполнения любого набора требований (уроки + тесты + работы). Только после выполнения всех требований пользователь получает награду.

```prisma
model LessonChallenge {
  id          String   @id @default(cuid())
  challengeId String   @unique
  content     String   @db.Text   // HTML-контент урока (видео, текст, ссылки)
  
  challenge   Challenge @relation(fields: [challengeId], references: [id], onDelete: Cascade)
  
  @@index([challengeId])
}
```

### 2.3 Добавить модель LessonCompletion (отслеживание просмотров)

```prisma
model LessonCompletion {
  id            String   @id @default(cuid())
  challengeId   String
  userId        String
  firstViewedAt DateTime @default(now())
  lastViewedAt  DateTime @updatedAt
  
  challenge Challenge @relation(fields: [challengeId], references: [id])
  user      User      @relation(fields: [userId], references: [id])
  
  @@unique([challengeId, userId])
  @@index([userId])
  @@index([challengeId])
}
```

### 2.4 Обновить Challenge (добавить связь с LessonChallenge)


## 4. Логика работы

### 4.1 При открытии страницы урока

**URL:** `/account/certification/lessons/[id]`

**Алгоритм:**
1. Получить `challenge` по `id` из params
2. Проверить, что `challenge.type = LESSON` и `challenge.isActive = true`
3. Если нет — redirect на `/account/certification`
4. Получить `LessonChallenge` с контентом
5. Проверить, есть ли `LessonCompletion` для `(userId, challengeId)`
6. Если нет — создать запись в `LessonCompletion` (первый просмотр)
7. Если есть — обновить `lastViewedAt`
8. Отобразить HTML-контент в безопасном режиме

### 4.2 В детальной странице сертификации

**Файл:** `app/account/certification/[id]/page.tsx`

**Добавить обработку типа LESSON:**

В цикле по `certification.requirements` добавить проверку:

```typescript

  const completion = await prisma.lessonCompletion.findFirst({
    where: {
      userId: user.id,
      challengeId: req.challengeId,
    },
```

**Отображение в карточке требования:**

| Тип | Значок | Цвет | Ссылка |
|-----|--------|------|--------|
| TEST | BookOpen | синий | `/account/certification/tests` |
| WORK | FileText | фиолетовый | `/account/certification/works` |
| LESSON | Play | зелёный | `/account/certification/lessons/[id]` |

## 6. API и Server Actions

### 6.1 Для клиента

```typescript
// Получить урок для просмотра
export async function getLesson(challengeId: string, userId: string) {
  const challenge = await prisma.challenge.findUnique({
    where: { id: challengeId, type: 'LESSON', isActive: true },
    include: { lesson: true },
  });
  
  if (!challenge) return null;
  
  const completion = await prisma.lessonCompletion.findUnique({
    where: {
      challengeId_userId: {
        challengeId: challenge.id,
        userId,
      },
    },
  });
  
  return {
    challenge,
    content: challenge.lesson?.content,
    isCompleted: !!completion,
  };
}

// Отметить урок как просмотренный (вызывается при открытии страницы)
export async function markLessonAsViewed(challengeId: string, userId: string) {
  return prisma.lessonCompletion.upsert({
    where: {
      challengeId_userId: {
        challengeId,
        userId,
      },
    },
    update: { lastViewedAt: new Date() },
    create: {
      challengeId,
      userId,
      firstViewedAt: new Date(),
    },
  });
}
```

## 7. Клиентская страница урока

**Файл:** `app/account/certification/lessons/[id]/page.tsx`

**Интерфейс:**
- Хлебные крошки: Сертификации → Уроки → Название урока
- Заголовок урока
- HTML-контент (в безопасном рендере)
- Статус внизу: "Пройден" / "Не пройден" (обновляется автоматически)

**Особенности:**
- При загрузке страницы вызывается `markLessonAsViewed`
- HTML-контент рендерится через `dangerouslySetInnerHTML` с предварительной санитизацией
- Адаптивный дизайн (на мобильных — отступы, читабельный шрифт)

**Компонент-заглушка для неактивных уроков:**

Если урок ещё не разблокирован (проверить `ChallengeUserState` или `price`), показывать плашку с предложением оплатить (аналогично работам).

## 11. Ограничения и допущения

- Урок нельзя "пройти" повторно — запись о просмотре создаётся один раз
- Повторное открытие урока обновляет `lastViewedAt`, но не создаёт дубликат
- HTML-контент санитизируется перед сохранением и перед показом
- Видео вставляются через iframe (YouTube, Vimeo и т.д.)
- Если урок платный — логика разблокировки аналогична работам (поле `price` в Challenge)
