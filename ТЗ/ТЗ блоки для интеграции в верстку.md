# Техническое задание: Система блоков с поддержкой скриптов и head-вставки

## 1. Обновление модели Block

```prisma
model Block {
  id          String   @id @default(cuid())
  slug        String   @unique
  name        String
  content     String?   // HTML-код, инлайн-скрипт или URL внешнего скрипта
  description String?
  isActive    Boolean  @default(true)
  
  // Новые поля
  isScript    Boolean  @default(false)  // true = JavaScript-скрипт, false = обычный HTML
  inHead      Boolean  @default(false)  // true = вставляется в <head>, false = в тело страницы
  order       Int      @default(0)      // Порядок вывода на сайте (для блоков в head и body)
  
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

### Пояснения:
- **`isScript`** — определяет, как обрабатывать блок: как обычный HTML или как скрипт
- **`inHead`** — блок попадает в `<head>` (скрипты аналитики, мета-теги) или в тело страницы (футер, баннеры)
- **`order`** — порядок вывода блоков на сайте (сначала меньшие значения). Актуально как для head, так и для body
- **`content`** — для HTML: обычная разметка; для скриптов: либо URL (если начинается с http), либо полный JS-код

## 3. Компонент-рендерер блоков

```jsx
// app/components/BlockRenderer.jsx
import Script from 'next/script'

/**
 * Рендерит блоки в зависимости от их типа
 * @param {Array} blocks - массив блоков из БД
 * @param {string} variant - 'head' или 'body' (фильтрует по inHead)
 */
export default function BlockRenderer({ blocks, variant = 'body' }) {
  const filteredBlocks = blocks
    .filter(block => block.isActive)
    .filter(block => variant === 'head' ? block.inHead : !block.inHead)
    .sort((a, b) => (a.order || 0) - (b.order || 0))

  return filteredBlocks.map(block => {
    // Обработка скриптов
    if (block.isScript) {
      const isExternal = block.content?.trim().startsWith('http')
      
      if (isExternal) {
        return (
          <Script 
            key={block.id}
            src={block.content}
            strategy="afterInteractive"
          />
        )
      }
      
      return (
        <Script 
          key={block.id}
          id={`script-${block.id}`}
          strategy="afterInteractive"
          dangerouslySetInnerHTML={{ __html: block.content || '' }}
        />
      )
    }
    
    // Обычные HTML-блоки
    return (
      <div 
        key={block.id}
        dangerouslySetInnerHTML={{ __html: block.content || '' }}
      />
    )
  })
}
```

## 4. Интеграция в глобальный лейаут

```jsx
// app/layout.js
import { prisma } from '@/lib/prisma'
import BlockRenderer from '@/components/BlockRenderer'

async function getAllBlocks() {
  return await prisma.block.findMany({
    where: { isActive: true },
    orderBy: { order: 'asc' }
  })
}

export default async function RootLayout({ children }) {
  const allBlocks = await getAllBlocks()
  
  return (
    <html lang="ru">
      <head>
        {/* Статические мета-теги */}
        <meta charSet="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1" />
        
        {/* Динамические блоки для head */}
        <BlockRenderer blocks={allBlocks} variant="head" />
      </head>
      <body>
        {/* Блоки для body — можно разместить где угодно */}
        {/* Например, в начале body */}
        <BlockRenderer blocks={allBlocks} variant="body" />
        
        {children}
      </body>
    </html>
  )
}
```

## 5. Использование в любом месте сайта

```jsx
// app/components/Footer.jsx
import { prisma } from '@/lib/prisma'
import BlockRenderer from '@/components/BlockRenderer'

async function getFooterBlocks() {
  return await prisma.block.findMany({
    where: { 
      isActive: true,
      inHead: false,  // только body-блоки
      slug: { contains: 'footer' }  // опционально: фильтр по slug
    },
    orderBy: { order: 'asc' }
  })
}

export default async function Footer() {
  const blocks = await getFooterBlocks()
  
  return (
    <footer>
      <BlockRenderer blocks={blocks} variant="body" />
    </footer>
  )
}
```

## 7. Важные технические моменты

| Ситуация | Как обрабатывается |
|----------|-------------------|
| HTML-блок содержит `<script>` | Скрипт НЕ выполнится (ограничение `dangerouslySetInnerHTML`) |
| Скрипт-блок с несколькими скриптами внутри | Всё выполнится как единый скрипт |
| Пустой content | Блок игнорируется |
| Внешний скрипт без http в начале | Обрабатывается как инлайн-скрипт |
| Несколько скриптов в одном блоке | Допустимо, но лучше разделить для гибкости |
