### 2️⃣ Модели данных

#### 2.1. Дополнение модели User

```prisma
model User {
  // ... существующие поля
  balance Int @default(0) // текущий баланс в копейках (целое число)
}
```

#### 2.2. Модель Transaction

```prisma
enum TransactionType {
  DEPOSIT      // пополнение счёта (внешняя оплата или ручное зачисление)
  WITHDRAWAL   // вывод средств (заявка на вывод)
  PURCHASE     // списание за услугу (разблокировка теста, проверка работы)
  EARNING      // начисление супервизору за проверку
}

model Transaction {
  id          String         @id @default(cuid())
  userId      String
  type        TransactionType
  amount      Int            // сумма в копейках (положительная для DEPOSIT/EARNING, отрицательная для PURCHASE/WITHDRAWAL)
  balance     Int            // баланс ПОСЛЕ операции (кеш, для быстрых запросов)
  description String         // краткое описание операции
  metadata    Json?          // дополнительная информация (serviceId, paymentId, adminId и т.д.)
  createdAt   DateTime       @default(now())

  user        User           @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@index([userId])
  @@index([createdAt])
  @@index([type])
}
```

**Миграция:**

```bash
npx prisma migrate dev --name add_balance_and_transactions
npx prisma generate
```

#### 3.2. Получение истории транзакций

```typescript
export async function getTransactions(
  userId: string,
  page: number = 1,
  limit: number = 20
): Promise<{
  items: Transaction[];
  total: number;
  page: number;
  limit: number;
  hasMore: boolean;
}>
```

**Логика:**
- Пагинация (`skip`, `take`)
- Сортировка по `createdAt` (новые сверху)
- Фильтрация по `userId`

---

#### 3.3. Проверка достаточности средств

```typescript
export async function hasSufficientFunds(
  userId: string,
  requiredAmount: number
): Promise<boolean>
```

**Логика:** `user.balance >= requiredAmount` (сумма в копейках).

---

#### 3.4. Списание средств за услугу

```typescript
export async function chargeForService(
  userId: string,
  amount: number,
  description: string,
  metadata?: { serviceId: string; serviceType: string }
): Promise<{ success: boolean; error?: string; newBalance?: number }>
```

**Логика:**
1. Проверка достаточности средств
2. Транзакция:
   - Уменьшение `user.balance`
   - Создание записи в `Transaction` (тип `PURCHASE`, отрицательная сумма)
3. Возврат нового баланса

---

#### 3.5. Пополнение счёта (внешняя оплата)

```typescript
export async function depositFunds(
  userId: string,
  amount: number,
  paymentId: string,
  description: string
): Promise<{ success: boolean; error?: string; newBalance?: number }>
```

**Логика:**
1. Проверка, что платёж с `paymentId` не был уже обработан
2. Транзакция:
   - Увеличение `user.balance`
   - Создание записи в `Transaction` (тип `DEPOSIT`, положительная сумма)
3. Возврат нового баланса

---

#### 3.6. Ручное зачисление (админ)

```typescript
export async function manualDeposit(
  userId: string,
  amount: number,
  reason: string
): Promise<{ success: boolean; error?: string; newBalance?: number }>
```

**Логика:**
- Проверка прав администратора
- Увеличение баланса
- Создание транзакции с типом `DEPOSIT` и пометкой `manual: true` в `metadata`

---

#### 3.7. Начисление супервизору (за проверку)

```typescript
export async function creditSupervisor(
  supervisorId: string,
  amount: number,
  reviewId: string,
  description: string
): Promise<{ success: boolean; error?: string; newBalance?: number }>
```

**Логика:**
- Увеличение баланса супервизора
- Создание транзакции с типом `EARNING`
- Связь с `reviewId` в `metadata`

---

#### 3.8. Пересчёт баланса из транзакций (для сверки)

```typescript
export async function recalculateBalance(userId: string): Promise<number>
```

**Логика:**
- Суммировать все `amount` из транзакций пользователя
- Обновить `user.balance`
- Вернуть вычисленный баланс

### 4️⃣ Логика использования

#### 4.1. При разблокировке теста

```typescript
const hasFunds = await hasSufficientFunds(userId, test.unlockPrice);
if (!hasFunds) {
  return { error: "Недостаточно средств" };
}

await chargeForService(userId, test.unlockPrice, `Разблокировка теста "${test.title}"`, {
  serviceId: test.id,
  serviceType: "test_unlock"
});

// Увеличить attemptsLeft
```

#### 4.2. При отправке работы на проверку супервизору

```typescript
const hasFunds = await hasSufficientFunds(userId, work.reviewPrice);
if (!hasFunds) {
  return { error: "Недостаточно средств для оплаты проверки" };
}

await chargeForService(userId, work.reviewPrice, `Проверка работы "${work.title}"`, {
  serviceId: work.id,
  serviceType: "work_review"
});

// Создать попытку, отправить супервизору
```

#### 4.3. При завершении проверки супервизором

```typescript
await creditSupervisor(supervisorId, work.reviewPrice, review.id, `Проверка работы пользователя ${user.fullName}`);
```
