## 3. Новые модели

```prisma
// ==================== КУРСЫ ====================

model Course {
  id          String   @id @default(cuid())
  slug        String   @unique          // "pp", "pm", "pa", "mak"
  title       String                    // "Психолог-практик"
  shortTitle  String                    // "ПП" — для бейджей
  description String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  enrollments UserCourse[]
  keys        CourseKey[]

  @@index([slug])
}

// ==================== СВЯЗЬ ПОЛЬЗОВАТЕЛЬ-КУРС ====================

model UserCourse {
  id         String   @id @default(cuid())
  userId     String
  courseId   String
  status     String   // "enrolled" или "graduated"
  assignedAt DateTime @default(now())

  user   User   @relation(fields: [userId], references: [id], onDelete: Cascade)
  course Course @relation(fields: [courseId], references: [id], onDelete: Cascade)

  @@unique([userId, courseId])
  @@index([userId])
  @@index([courseId])
  @@index([status])
}

// ==================== ПРОМОКОДЫ ====================

model CourseKey {
  id         String   @id @default(cuid())
  courseId   String
  key        String   @unique
  status     String   // "enrolled" или "graduated"
  maxUses    Int      @default(1)       // 0 — без ограничений
  usedCount  Int      @default(0)
  expiresAt  DateTime?
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt

  course Course @relation(fields: [courseId], references: [id], onDelete: Cascade)
  uses   CourseKeyUse[]

  @@index([key])
  @@index([courseId])
}

model CourseKeyUse {
  id         String   @id @default(cuid())
  keyId      String
  userId     String
  usedAt     DateTime @default(now())

  key  CourseKey @relation(fields: [keyId], references: [id], onDelete: Cascade)
  user User      @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@index([keyId])
  @@index([userId])
}
```

### 5.2. Список курсов (`/admin/courses`)

| Элемент | Действие |
|---------|----------|
| Заголовок "Курсы" | |
| Кнопка [+ Создать] | → форма создания курса |
| Карточка курса | Отображает: название, короткое название, slug, количество учеников и выпускников |
| [Промокоды] | → страница промокодов курса |
| [Редактировать] | → форма редактирования |
| [Удалить] | Подтверждение → удаляет курс и связанные промокоды (UserCourse не удаляются, остаются для истории) |

### 5.3. Форма курса (`/admin/courses/new`, `/admin/courses/[id]/edit`)

| Поле | Тип | Обязательное |
|------|-----|--------------|
| Название | text | да |
| Короткое название | text | да |
| Slug | text | да |
| Описание | textarea | нет |

---

### 5.4. Промокоды курса (`/admin/courses/[id]/keys`)

**Список промокодов:**
- Ключ
- Тип (ученик/выпускник)
- Использовано / Максимум
- Срок действия
- Кнопки: [Скопировать], [Редактировать], [Деактивировать]/[Удалить]

**Кнопка [+ Создать]** → форма создания промокода

**Форма создания промокода:**
| Поле | Тип | Пояснение |
|------|-----|-----------|
| Ключ | text | опционально, если пусто — генерируется |
| Тип | radio | ученик / выпускник |
| Лимит использований | number | 0 — без ограничений |
| Срок действия | date / бессрочно | опционально |

### 6.3. Логика активации

1. Пользователь вводит ключ
2. Проверка:
   - Ключ существует
   - Не истёк срок
   - Не превышен лимит использований
3. Если всё ок:
   - Проверяем, есть ли уже запись в `UserCourse` для этого курса
   - Если нет — создаём
   - Если есть — пропускаем (не дублируем)
   - Увеличиваем `usedCount` у ключа
   - Создаём запись в `CourseKeyUse`
4. Показываем сообщение об успехе или ошибке

## 10. Обработка ошибок

| Ситуация | Сообщение |
|----------|-----------|
| Ключ не найден | «Ключ не найден» |
| Ключ истёк | «Срок действия ключа истёк» |
| Лимит использований исчерпан | «Ключ больше не действителен» |
| Ключ уже активирован пользователем | «Вы уже активировали этот ключ» |
| Пользователь не авторизован | «Необходимо войти в систему» |
