## 📋 ТЗ: Дашборд админки

### 1️⃣ Общая информация

**Проект:** Давай вместе — каталог психологов  
**Технологии:** Next.js 16 (App Router), Tailwind CSS  
**Тип задачи:** Создание дашборда (главной страницы админки) с блоками, требующими внимания модератора

**Расположение:** `app/admin/page.tsx` (используется существующий layout админки)

---

### 2️⃣ Структура дашборда

#### 2.1 **Красный блок — Срочно на модерацию**

Отображаются карточки с количеством элементов, требующих модерации:

| Карточка | Откуда берём | Условие | Ссылка |
|----------|-------------|---------|--------|
| **Профили** | `User` | `draftData` не `null` и статус черновика `PENDING` | `/admin/moderation/profiles` |
| **Документы** | `Document` | `verifiedAt = null` и тип не `PHOTO` | `/admin/moderation/documents` |
| **Фото профилей** | `Document` | `verifiedAt = null` и тип `PHOTO` | `/admin/moderation/photos` |
| **Статьи** | `Article` | `moderationStatus = PENDING` | `/admin/moderation/articles` |
| **Сообщения** | `Message` | `direction = "to_user"` и `isRead = false` (непрочитанные сообщения для модераторов) | `/admin/messages` |

**Визуализация:** сетка карточек (5 штук), каждая с заголовком, числом и ссылкой.

---

#### 2.2 **Синий блок — Проблемные заявки**

| Показатель | Условие | Ссылка |
|------------|---------|--------|
| **Нет ответа > 2 дней** | Статус `NEW` и `createdAt` старше 2 дней | `/admin/leads?status=NEW&old=2days` |
| **Нет прогресса > 10 дней** | Статус `ACCEPTED` и `statusChangedAt` старше 10 дней | `/admin/leads?status=ACCEPTED&old=10days` |

**Визуализация:** две строки с количеством и ссылкой на отфильтрованный список.

---

#### 2.3 **Оранжевый блок — Долги по статьям**

| Показатель | Условие |
|------------|---------|
| **Психологи с просроченной статьёй** | Активные психологи (`status = ACTIVE`), у которых нет одобренной статьи (`APPROVED`) за текущий месяц |
| **Психологи в зоне риска** | Активные психологи, у которых последняя одобренная статья была в прошлом месяце (долг за текущий месяц, но ещё можно написать) |

**Визуализация:** список психологов (ФИО, email, дата последней статьи) с ссылкой на профиль в админке.

### 3️⃣ Технические требования

#### 3.1 **Server Action** (`lib/actions/admin-dashboard.ts`)

```typescript
export async function getDashboardStats()
```

Возвращает объект:
```typescript
{
  moderation: {
    profiles: number
    documents: number
    photos: number
    articles: number
    unreadMessages: number
  },
  problematicLeads: {
    noResponseOver2Days: number
    noProgressOver10Days: number
  },
  articleDebts: {
    overdue: Array<{ id, fullName, email, lastArticleDate }>
    atRisk: Array<{ id, fullName, email, lastArticleDate }>
  }
}
```

#### 3.2 **Компоненты**

Все компоненты хранятся в `components/admin/dashboard/`:
- `ModerationCards.tsx` — карточки срочной модерации
- `ProblematicLeads.tsx` — проблемные заявки
- `ArticleDebts.tsx` — долги по статьям
- `DashboardClient.tsx` — клиентский компонент-обёртка (если нужна интерактивность)

#### 3.3 **Страница** (`app/admin/page.tsx`)

- Серверный компонент
- Вызывает `getDashboardStats()`
- Рендерит три блока
