Способы интеграции

Платежная форма банка

Платежная форма банка — способ интеграции интернет-эквайринга для работы с готовой платежной формой Т-Банка.

Она используется при проведении платежей через:

  • создание ссылки на оплату,
  • редирект на платежную форму банка,
  • открытие платежной формы в iframe,
  • мобильное приложение,
  • модули для CMS.

Создание ссылки на оплату

Создание ссылки на оплату — способ интеграции, который позволяет принимать платежи через ссылки. Вы отправляете ссылку на оплату покупателю — на электронную почту, по СМС, в соцсеть или мессенджер.

Интеграцию не нужно настраивать — достаточно сгенерировать одноразовую или многоразовую ссылку на оплату через личный кабинет интернет‑эквайринга и отправить покупателю самостоятельно.

Кому подойдет: мерчантам без сайта.

Также этот способ подходит, если у вас нет возможности настроить интеграцию с интернет-эквайрингом.

Редирект на платежную форму банка

Редирект на платежную форму банка — способ интеграции интернет‑эквайринга через вызов метода Инициировать платеж с передачей суммы платежа и номера заказа.

Ссылка на платежную форму вернется в ответе метода в параметре PaymentURL. Для проведения платежа нужно провести редирект покупателя на полученную ссылку.

Кому подойдет: мерчантам с самописным сайтом.

Открытие платежной формы в iframe

Открытие платежной формы в iframe — cпособ интеграции интернет‑эквайринга в ваше приложение, который позволяет открывать платежную форму в любом месте сайта в iframe-элементе.

Кому подойдет: мерчантам с самописным сайтом.

Мобильное приложение

Мобильное приложение — способ интеграции интернет-эквайринга с платежной формой WebView, который позволяет отобразить ее в вашем мобильном приложении.

Кому подойдет: мерчантам, у которых помимо самописного сайта есть мобильное приложение.

Модули для CMS

Модули для CMS — cпособ интеграции интернет-эквайринга с готовым платежным модулем внутри CMS. Позволяет принимать платежи через платежную форму банка без дополнительной разработки.

Кому подойдет: мерчантам, чей сайт создан на поддерживаемых Т‑Банком CMS.

Кнопки быстрой оплаты

Кнопки быстрой оплаты — способ интеграциии интернет‑эквайринга для настройки оплаты в один клик через добавление на сайт виджета с кнопками оплаты.

Кому подойдет: мерчантам с самописным сайтом.

Своя платежная форма

Своя платежная форма — способ интеграциии интернет-эквайринга через API. Позволяет использовать собственную платежную форму и интегрировать свой сайт с API Т-Банка напрямую.

Кому подойдет: мерчантам, у которых есть свой интерфейс для хранения и работы с данными покупателей или для тех, кто планирует его создать.
